# Data access

This repository contains analysis scripts, figure-generation code, and non-sensitive aggregate result files used for the manuscript.

Raw sequencing data, participant-level clinical metadata, raw RNA-seq count matrices, raw metagenomic abundance matrices, and sample-to-participant mapping files are not included because they are subject to data-use and privacy restrictions.

Sequencing data are available by request through the IBD Plexus:
https://www.crohnscolitisfoundation.org/research/plexus/academic-request-for-proposal

Users with approved data access may run the scripts after updating the input file paths to point to their local copies of the required data.
